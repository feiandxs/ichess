# Nook Flat

Original geometric chess artwork drawn for Nook Chess. Created 2026-09-17 from newly authored SVG paths, circles and shared proportions. No third-party chess piece image or SVG path was used as an input or traced.

Twelve transparent SVGs share a 64 × 72 coordinate system, flat fills and a 2.8-unit outline. PNGs are rasterized at 256 × 288 using @resvg/resvg-js, via scripts/pack_piece_sets.mjs. These source vectors are the editable masters.

Revision 2: removed the knight neck detail, rounded the silhouette and bases, widened the set by 10% and shortened it by 9% around the baseline. Revision 1 is preserved in artwork/nook-flat-v1.

Revision 3: centered silhouettes and on-board positioning, enlarged king cross and queen crown tips, simplified and filled out bodies across all six kinds. Revision 2 is preserved in artwork/nook-flat-v2.
