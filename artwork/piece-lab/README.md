# piece-lab

Generator for the five original square piece sets (nook-soft, nook-crisp, nook-block, nook-mono, nook-badge). `sets.mjs` holds the drawings; `gen.mjs` writes `sets/<id>/<side>_<piece>.svg` (and a contact sheet) when run from this directory; copy the results into `artwork/nook-<id>/`. `build.mjs` + `template.html` build a comparison page. All artwork is original to this project.
